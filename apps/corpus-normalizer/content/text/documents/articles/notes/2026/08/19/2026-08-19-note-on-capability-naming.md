A services-section is named for the capability it engineers. A capability name presumes
a stream of work - engines, content pipelines, multiple shipped apps as leaves - and
accumulates over time. An invented title presumes a single artifact and closes off scope
at the moment of coinage.

Titles (for example Cowrie, Palaverse, or any per-game display name) are a separate,
optional display layer: applied later, atop a section that was already named for what it
does. Engines are named for pioneers or plain nouns per existing convention; neither an
engine name nor a display title is a substitute for a capability name.

## Gaming estate mapping

The following mapping applies the rule to the gaming estate. It is a proposal pending
review against existing section-naming grammar; display names, where kept, live in brand
files and app metadata, not in section names.

| Title-style name | Capability section |
| --- | --- |
| "Seasonal Round" | settlement-management-game-engineering-services-section |
| "Crucible" | obstruction-puzzle-game-engineering-services-section |
| "Stoke" | incremental-game-engineering-services-section |
| "Kelly's Wager" / gambling-trainer | probability-education-game-engineering-services-section |
| parlor pack | parlor-game-engineering-services-section |
| solitaire | card-game-engineering-services-section (solitaire an app within) |
| "Tidepool" / undersea MUD line | multi-user-dungeon-game-engineering-services-section |
| Farstone QBN | quality-based-narrative-game-engineering-services-section (Farstone a world within) |
| durante + daily arena | first-person-shooter-game-engineering-services-section |
| "VaultMaze" | knowledge-vault-game-engineering-services-section |
| Okaga game line | persistent-world-game-engineering-services-section (Okaga a paracosm within) |
| "Palaverse" | game-federation-services-section (Palaverse remains the display name) |
| TileSlots/onestone | tile-matching-game-engineering-services-section |
| weiqi line | already correctly capability-named (weiqi-services-section) |

The weiqi section is the model: named for its subject, holding kernel, apps, glossary,
lessons, and tooling as leaves. It is also the section that has been extended most
successfully, which is not a coincidence.
